# Mealmate 🍽️
A social dining platform that helps people in Vancouver meet new friends and avoid eating alone. Users can create postings for restaurant meetups, and others can join — simple, friendly, and spontaneous.

---

## Features

### 👥 Create & Join Meal Postings
- Anyone can create a posting for a Vancouver restaurant.
- Users can browse and join postings with one click.
- Includes time, location, available seats, and a short description.

### 🤝 Meet New People
- Each posting forms a group dining meetup.
- Encourages social connection and reduces the awkwardness of dining alone.

### 📱 Modern Web App Stack
- **React** frontend
- **FastAPI (Python)** backend
- **Supabase** for database, auth, and storage
